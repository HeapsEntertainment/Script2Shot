# External App Intergations Overview

# Script Writing Software
## Story Architect (STARC)
Open your STARC project, and select your screenplay file.
_Right-click>Export_. Under format, select Fountain.
Once saved, your screenplay can now be imported into Script2Shot.

# Tables & Spreadsheets
## Microsoft Excel & Google Sheets
### Step 1
Go to _File>Export_, and select _Excel (.xls)_.
### Step 2
Open Excel or Google Sheets. You may receive a warning modal. This is because the file was generated by a html based app. Select "Yes" or "Okay".
### Step 3
If the file is open in a mode such as "Read Only" or "Viewing", be sure to toggle to "Edit Mode".

## Microsoft Word or Google Docs
### Step 1
Go to _File>Export_, and select _PDF_.
### Step 2
Open a conversion tool, such as __https://www.freeconvert.com/pdf-to-docx__
### Step 3
Convert the PDF file to .docx format, and save.
### Step 4
Open in Word or Google Docs. You may receive a warning modal. Select "Yes" or "Okay".
### Step 5
If the file is open in a mode such as "Read Only" or "Viewing", be sure to toggle to "Edit Mode".

# External Shotlist Tools supporting CSV
### Step 1
Go to _File>Export_, and select _CSV_.
### Step 2
Open your shotlist tool of choice that supports CSV import. Examples include:
* CuePilot
* Scenechronize
* Yamdu
* Filmustage
### Step 3
Locate the import tool (For example, _File>Import>.csv_).

# Animation Software
## Blender
Script2Shot currently can't be integrated directly into Blender. However, it does include Blender presets for render time calculation.
